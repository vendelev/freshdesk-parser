## Integration тесты (Infrastructure слой)

### `tests/Suite/Backup/Infrastructure/FreshdeskHttpClientAdapterTest.php`

**Назначение**: Тестирование адаптера для работы с Freshdesk API.

#### Сценарий 1: ✅ Успешное получение одной страницы задач

**Дано**:
- Guzzle mock возвращает JSON ответ с 50 задачами
- Ответ содержит поле `meta.total` = 50

**Проверяемое**:
- Адаптер выполняет GET запрос на правильный URL
- Адаптер передает API key в заголовки
- Адаптер преобразует JSON в array
- Возвращаемый array содержит 50 элементов

**Ожидаемый результат**: Тест проходит, array содержит все задачи

#### Сценарий 2: ✅ Пагинация (несколько страниц)

**Дано**:
- Первый запрос возвращает page 1/3 (100 задач, есть next_page)
- **Задержка 1 сек**
- Второй запрос возвращает page 2/3 (100 задач, есть next_page)
- **Задержка 1 сек**
- Третий запрос возвращает page 3/3 (50 задач, нет next_page)

**Проверяемое**:
- Адаптер выполняет 3 запроса в правильном порядке
- Между запросами есть задержка (sleep(1))
- Все 250 задач объединены в один array
- Конечный array отсортирован правильно

**Ожидаемый результат**: Тест проходит, все 250 задач получены и объединены

#### Сценарий 3: ✅ Rate limiting (429)

**Дано**:
- Первый запрос возвращает HTTP 429 (Too Many Requests)
- Retry механизм ждет и повторяет запрос
- Второй запрос (повтор) успешен и возвращает данные

**Проверяемое**:
- Адаптер обрабатывает 429 статус код
- Реализует exponential backoff с максимум 3 попытками
- После успешного retry возвращает правильные данные

**Ожидаемый результат**: Тест проходит, retry логика работает

#### Сценарий 4: ✅ Connection timeout

**Дано**:
- Guzzle выбрасывает ConnectException при выполнении запроса

**Проверяемое**:
- Адаптер перехватывает ConnectException
- Преобразует в FreshdeskApiConnectionException
- Не выполняет retry для этого типа ошибки

**Ожидаемый результат**: Тест проходит, исключение преобразовано правильно

#### Сценарий 5: ✅ Invalid API key (401)

**Дано**:
- HTTP ответ с статус кодом 401 (Unauthorized)

**Проверяемое**:
- Адаптер преобразует 401 в FreshdeskApiUnauthorizedException
- Сообщение об ошибке указывает на проблему с авторизацией

**Ожидаемый результат**: Тест проходит

### `tests/Suite/Backup/Infrastructure/FileBackupStorageAdapterTest.php`

**Назначение**: Тестирование адаптера для сохранения бекапа в файловую систему.

#### Сценарий 1: ✅ Успешная запись файла

**Дано**:
- Массив данных для сохранения (meta + tickets)
- Имя файла: `backup_2025-01-15_103000.json`
- Директория существует и доступна для записи

**Проверяемое**:
- Адаптер создает файл в правильной директории
- Файл содержит валидный JSON
- JSON структура правильная:
  ```json
  {
    "meta": {
      "created_at": "2025-01-15T10:30:00Z",
      "total_tickets": 250
    },
    "tickets": [...]
  }
  ```
- JSON отформатирован для читаемости (json_encode с JSON_PRETTY_PRINT)

**Ожидаемый результат**: Тест проходит, файл создан с правильным содержимым

#### Сценарий 2: ✅ Перезапись существующего файла

**Дано**:
- Файл `backup_YYYY-MM-DD_HHmmss.json` уже существует
- Новые данные отличаются от старых

**Проверяемое**:
- Адаптер перезаписывает старый файл
- Новые данные полностью заменяют старые
- Старые данные больше недоступны

**Ожидаемый результат**: Тест проходит, файл перезаписан

#### Сценарий 3: ✅ Создание директории

**Дано**:
- Директория для сохранения не существует
- Путь: `storage/backups/`

**Проверяемое**:
- Адаптер автоматически создает директорию
- Файл сохраняется в созданную директорию
- Директория имеет правильные права доступа

**Ожидаемый результат**: Тест проходит, директория создана

#### Сценарий 4: ✅ Ошибка записи

**Дано**:
- Недостаточно прав для записи в директорию
- Или: диск заполнен

**Проверяемое**:
- Адаптер выбрасывает BackupStorageWriteException
- Сообщение об ошибке указывает на проблему
- Файл не создается

**Ожидаемый результат**: Тест проходит, исключение выброшено правильно

## Чек-лист выполнения тестов

### Перед запуском тестов

- [ ] Все файлы созданы (фазы 1-5 из TaskForDev.md)
- [ ] Зависимости установлены (Composer, Guzzle)
- [ ] Переменные окружения настроены (.env, .env.testing)

### Запуск тестов

```bash
# Все тесты модуля Backup
make php-run CMD="php vendor/bin/phpunit tests/Suite/Backup"

# Отдельно по слоям
make php-run CMD="php vendor/bin/phpunit tests/Suite/Backup/Application"
make php-run CMD="php vendor/bin/phpunit tests/Suite/Backup/Infrastructure"
make php-run CMD="php vendor/bin/phpunit tests/Suite/Backup/Presentation"
```

```bash
# PHPStan
make php-run CMD="php vendor/bin/phpstan analyse src/Backup"

# PHP CodeSniffer
make php-run CMD="php vendor/bin/phpcs src/Backup"
```
