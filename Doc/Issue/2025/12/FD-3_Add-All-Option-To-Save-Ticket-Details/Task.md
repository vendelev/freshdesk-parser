# FD-3: Добавление опции --all для сохранения детальной информации о всех задачах

## Описание
Реализация функциональности для сохранения детальной информации о всех задачах из существующих бекапов с помощью опции `--all` в команде `backup:ticket-details`.

## Файлы реализации
- [TaskForDev.md](TaskForDev.md) - Технический план для разработчика
- [TaskForTest.md](TaskForTest.md) - План тестирования

- **Примерное время реализации**: 4-6 часов
- **Зависимости**: FD-1 (Backup Module), FD-2 (Ticket Detail Module)
