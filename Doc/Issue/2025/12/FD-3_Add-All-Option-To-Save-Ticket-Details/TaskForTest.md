## Функциональные тесты (Application слой)

### SaveAllTicketDetailsUseCaseTest.php

#### Сценарий 1: Успешная обработка всех задач
**Дано**: 
- TicketListProviderInterface возвращает 3 ID задач: [1001, 1002, 1003]
- SaveTicketDetailUseCase успешно обрабатывает все задачи

**Проверяемое**: 
- Вызовы SaveTicketDetailUseCase для каждой задачи
- Возвращаемый ProcessingSummary с корректными значениями

**Ожидаемый результат**: 
- Все задачи обработаны успешно
- Summary: total=3, processed=3, skipped=0, failed=0

#### Сценарий 2: Частичные ошибки при обработке
**Дано**: 
- TicketListProviderInterface возвращает 3 ID задач: [1001, 1002, 1003]
- SaveTicketDetailUseCase успешно обрабатывает 2 задачи и возвращает ошибку для одной

**Проверяемое**: 
- Продолжение обработки после ошибки
- Корректное подсчет статистики

**Ожидаемый результат**: 
- Summary: total=3, processed=2, skipped=0, failed=1
- Ошибки не прерывают общий процесс

#### Сценарий 3: Пропуск существующих задач (без --force)
**Дано**: 
- TicketListProviderInterface возвращает 2 ID задач: [1001, 1002]
- Для задачи 1001 уже существуют детали (репозиторий возвращает true для exists())
- Для задачи 1002 деталей нет

**Проверяемое**: 
- Задача 1001 пропущена (не вызывается SaveTicketDetailUseCase)
- Задача 1002 обработана

**Ожидаемый результат**: 
- Summary: total=2, processed=1, skipped=1, failed=0

## Критерии приемки

### CA1: Корректная обработка всех задач
- [ ] Система успешно обрабатывает все задачи из существующих бекапов
- [ ] Система пропускает задачи с существующими деталями (без --force)
- [ ] Система перезаписывает детали при указании --force

### CA2: Обработка ошибок
- [ ] При ошибке обработки одной задачи система продолжает обработку остальных
- [ ] Система выводит сводку с количеством успешно обработанных, пропущенных и ошибочных задач

### CA3: Прогресс выполнения
- [ ] Система отображает прогресс выполнения при обработке множества задач
- [ ] Система выводит финальную сводку по завершении обработки

### CA4: Взаимодействие с существующими модулями
- [ ] Система корректно использует функциональность Backup модуля для получения списка задач
- [ ] Система корректно использует функциональность TicketDetail модуля для сохранения деталей
