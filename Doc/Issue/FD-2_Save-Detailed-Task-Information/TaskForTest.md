# Задача для тестирования: FD-2 Сохранение детальной информации о задачах

## Структура тестов

Тесты организованы в `backend/tests/Suite/TicketDetail/` согласно архитектуре:

- **Application/**: Unit и Functional тесты бизнес-логики
- **Infrastructure/**: Integration тесты адаптеров и репозиториев
- **Presentation/**: E2E тесты консольных команд

Каждый тест наследуется от `TestCase.php` и использует PHPUnit.

## Функциональные тесты (Application слой)

### SaveTicketDetailUseCaseTest

**Сценарий 1: Успешное сохранение детальной информации**
- **Дано**: Mock FreshdeskDetailClientInterface возвращает валидный JSON, Mock TicketDetailRepositoryInterface
- **Проверяемое**: Вызов UseCase::execute() с SaveTicketDetailRequest
- **Ожидаемый результат**: Возвращается SaveTicketDetailResponse со status='success', корректный filePath и savedAt

**Сценарий 2: Ошибка получения данных из Freshdesk**
- **Дано**: Mock FreshdeskDetailClientInterface выбрасывает исключение
- **Проверяемое**: Вызов UseCase::execute()
- **Ожидаемый результат**: Возвращается SaveTicketDetailResponse со status='failed', errorMessage заполнен

**Сценарий 3: Частичное получение данных**
- **Дано**: Mock возвращает JSON без conversations (имитация частичного ответа)
- **Проверяемое**: Вызов UseCase::execute()
- **Ожидаемый результат**: Сохранение происходит, status='partial' в метаданных

## Критерии приемки

### CA1: Успешное получение детальной информации

- [ ] При выполнении команды система получает полную детальную информацию задачи из Freshdesk API
- [ ] Детальная информация включает conversations, attachments и другие расширенные поля
- [ ] JSON сохраняется без изменений в файл

### CA2: Корректное сохранение данных

- [ ] Детальная информация сохраняется в отдельные JSON файлы по ID задачи в `storage/tickets/detail/`
- [ ] Файлы содержат метаданные о времени сохранения
- [ ] Существующие файлы перезаписываются при повторном сохранении

### CA3: Консольная команда

- [ ] Команда `php artisan ticket-details:save --all` доступна и выполняется без ошибок
- [ ] Команда `php artisan ticket-details:save --ticket-id=123` доступна для конкретной задачи
- [ ] Команда завершается с exit code 0 при успехе
- [ ] Команда выводит информацию о сохраненных данных (количество задач, время выполнения, статус)

### CA4: Обработка ошибок

- [ ] При недоступности Freshdesk система выводит понятное сообщение об ошибке
- [ ] При ошибке для одной задачи система продолжает обработку других задач
- [ ] Частично полученные данные сохраняются с соответствующей отметкой

### CA5: Безопасность

- [ ] API ключ хранится в переменных окружения
- [ ] API ключ не попадает в логи или вывод команды

### CA6: Справка команды

- [ ] Команда поддерживает флаг `--help`
- [ ] Флаг `--help` выводит описание синтаксиса команды и доступных опций

### CA7: Производительность

- [ ] Сохранение одной задачи завершается в разумное время (не более 30 секунд)
- [ ] Rate limits Freshdesk API соблюдаются с экспоненциальным backoff

### CA8: Надежность

- [ ] При частичном сбое система сохраняет успешно полученные данные
- [ ] Система корректно обрабатывает потери соединения с API
