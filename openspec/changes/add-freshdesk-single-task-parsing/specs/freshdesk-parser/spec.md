# Спецификация парсинга одной задачи из Freshdesk

## Purpose

Эта спецификация описывает функциональность парсера отдельной задачи из Freshdesk API по её ID. Парсер предназначен для извлечения данных конкретного тикета из Freshdesk API и сохранения их в локальной базе данных для дальнейшей обработки и анализа.

Спецификация следует принципам Specification-Driven Development и создана в соответствии с архитектурными принципами проекта.

## ADDED Requirements

### Requirement: Получение задачи из Freshdesk API по ID
Система SHALL предоставлять возможность получения задачи из Freshdesk API по её ID.
// Система ДОЛЖНА предоставлять возможность получения задачи из Freshdesk API по её ID.

#### Scenario: Успешное получение задачи по ID
Given система имеет доступ к Freshdesk API
When запрашивается задача с определенным ID
Then система получает данные задачи в формате JSON

#### Scenario: Получение несуществующей задачи
Given система имеет доступ к Freshdesk API
When запрашивается несуществующая задача
Then система получает ошибку 404

### Requirement: Сохранение JSON файла отдельной задачи
Система SHALL сохранять полученные данные отдельной задачи от Freshdesk API в файл формата JSON.
// Система ДОЛЖНА сохранять полученные данные отдельной задачи от Freshdesk API в файл формата JSON.

#### Scenario: Сохранение данных задачи в файл
Given система получила данные отдельной задачи от Freshdesk API
When данные сохраняются в файл
Then файл сохраняется в директории backend/storage/freshdesk/tasks/{id}.json

#### Scenario: Сохранение оригинальных данных задачи
Given система получила данные отдельной задачи от Freshdesk API
When данные сохраняются в файл
Then содержимое файла идентично ответу API без изменений

### Requirement: Обработка ошибок API при получении одной задачи
Система SHALL корректно обрабатывать ошибки авторизации (401), ошибки превышения лимита запросов (429) и ошибки отсутствия задачи (404) от Freshdesk API.
// Система ДОЛЖНА корректно обрабатывать ошибки авторизации (401), ошибки превышения лимита запросов (429) и ошибки отсутствия задачи (404) от Freshdesk API.

#### Scenario: Обработка ошибки авторизации при получении одной задачи
Given система отправляет запрос с неверными учетными данными
When API возвращает ошибку 401
Then система выбрасывает FreshdeskApiException

#### Scenario: Обработка ошибки лимита запросов при получении одной задачи
Given система отправляет слишком много запросов
When API возвращает ошибку 429
Then система делает паузу и повторяет запрос

#### Scenario: Обработка ошибки отсутствия задачи
Given система запрашивает несуществующую задачу
When API возвращает ошибку 404
Then система выбрасывает FreshdeskApiException
