# Delta: freshdesk-parser

## ADDED Requirements

### Requirement: Парсинг отдельной задачи по ID
Система SHALL предоставлять возможность получить одну задачу из Freshdesk API по её идентификатору `taskId` и сохранить исходный JSON-ответ в файл.

#### Scenario: Успешный парсинг и сохранение отдельной задачи
- **WHEN** пользователь запускает парсинг отдельной задачи с `taskId=12345`
- **THEN** система выполняет запрос к Freshdesk API для получения задачи `12345`
- **AND THEN** система сохраняет исходный JSON-ответ без модификаций в `backend/storage/freshdesk/freshdesk/tasks/12345.json`

#### Scenario: Запрошена несуществующая задача
- **WHEN** система запрашивает задачу с `taskId`, отсутствующим в Freshdesk
- **THEN** система обрабатывает ответ Freshdesk API со статусом 404 как ошибку получения задачи

#### Scenario: Ошибки авторизации и лимитов для отдельной задачи
- **WHEN** Freshdesk API отвечает со статусом 401
- **THEN** система завершает выполнение с ошибкой авторизации
- **WHEN** Freshdesk API отвечает со статусом 429
- **THEN** система выдерживает паузу и повторяет запрос
