# Delta: Парсинг одной задачи из Freshdesk

## ADDED Requirements

### Requirement: Получение данных одной задачи из Freshdesk API
Система SHALL предоставлять возможность получения данных одной конкретной задачи по её идентификатору из Freshdesk API.

#### Scenario: Успешное получение задачи по ID
Given система имеет доступ к Freshdesk API
When запрашивается задача с ID {task_id}
Then система получает объект задачи в формате JSON с полной информацией

#### Scenario: Получение несуществующей задачи
Given система имеет доступ к Freshdesk API
When запрашивается задача с ID, которая не существует
Then система выбрасывает FreshdeskApiException с кодом 404

### Requirement: Сохранение данных одной задачи в файл
Система SHALL сохранять полученные данные одной задачи от Freshdesk API в файл формата JSON.

#### Scenario: Сохранение данных задачи в файл
Given система получила данные одной задачи от Freshdesk API
When данные сохраняются в файл
Then файл сохраняется в директории backend/storage/freshdesk/freshdesk/tasks/ с именем {task_id}.json

#### Scenario: Сохранение оригинальных данных задачи
Given система получила данные одной задачи от Freshdesk API
When данные сохраняются в файл
Then содержимое файла идентично ответу API без изменений

#### Scenario: Создание директории при сохранении
Given директория backend/storage/freshdesk/freshdesk/tasks/ не существует
When данные сохраняются в файл
Then директория создается автоматически

### Requirement: Обработка ошибок при получении одной задачи
Система SHALL корректно обрабатывать различные ошибки при получении одной задачи.

#### Scenario: Обработка ошибки авторизации при запросе задачи
Given система отправляет запрос с неверными учетными данными
When API возвращает ошибку 401
Then система выбрасывает FreshdeskApiException

#### Scenario: Обработка ошибки лимита при запросе задачи
Given система отправляет запрос
When API возвращает ошибку 429 (превышение лимита)
Then система делает паузу и повторяет запрос

### Requirement: Консольная команда для получения одной задачи
Система SHALL предоставлять консольную команду для получения одной задачи по ID.

#### Scenario: Выполнение команды php artisan freshdesk:parse-task
Given пользователь имеет доступ к командной строке
When выполняется команда `php artisan freshdesk:parse-task {task_id}`
Then система получает и сохраняет задачу, отображая результат в консоли

#### Scenario: Обработка несуществующего ID в команде
Given пользователь выполнил команду с несуществующим ID
When команда завершает выполнение
Then система отображает ошибку в консоли
