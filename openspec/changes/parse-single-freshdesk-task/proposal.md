# Proposal: Парсинг одной задачи из Freshdesk API

## Why

Текущая функциональность позволяет загружать все задачи постранично, но отсутствует возможность получить данные по отдельной задаче по её идентификатору. Это необходимо для:

- Обновления информации об уже загруженной задаче
- Получения полной информации о конкретной задаче без загрузки всех остальных

## What Changes

Добавление новой функциональности для получения данных одной задачи из Freshdesk API с сохранением оригинального JSON в структурированный путь.

### From
```
// Отсутствие возможности получить одну задачу по ID из Freshdesk
```

### To
```
// Добавление UseCase для получения одной задачи:
// - Получение данных задачи из Freshdesk API по ID
// - Сохранение оригинального JSON в файл по пути: backend/storage/freshdesk/freshdesk/tasks/{номер задачи}.json
// - Возвращение Response с информацией о результате
```

## Impact

- **Affected specs**: `freshdesk-parser`
- **Affected code**: `backend/src/Task/`
- **Breaking Changes**: Нет
- **Migration**: Нет
- **Dependencies**: Нет
- **Performance**: Минимальное влияние, один синхронный HTTP запрос
