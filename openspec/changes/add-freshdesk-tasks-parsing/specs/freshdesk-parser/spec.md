# Спецификация парсинга задач из Freshdesk

## ADDED Requirements

### Requirement: Постраничная загрузка данных из Freshdesk API
#### Scenario: Успешная загрузка первой страницы задач
Given система имеет доступ к Freshdesk API
When запрашивается первая страница задач (page=1, per_page=100)
Then система получает массив из до 100 задач в формате JSON

#### Scenario: Загрузка последующих страниц задач
Given система успешно загрузила предыдущую страницу
When запрашивается следующая страница задач
Then система получает следующую порцию задач или пустой массив

### Requirement: Сохранение JSON файлов
#### Scenario: Сохранение данных в файл
Given система получила данные от Freshdesk API
When данные сохраняются в файл
Then файл сохраняется в директории backend/storage/freshdesk/ с именем tasks-{номер страницы}.json

#### Scenario: Сохранение оригинальных данных
Given система получила данные от Freshdesk API
When данные сохраняются в файл
Then содержимое файла идентично ответу API без изменений

### Requirement: Задержка между запросами
#### Scenario: Соблюдение интервала между запросами
Given система отправляет несколько запросов к API
When между запросами проходит пауза
Then пауза составляет не менее 1 секунды

### Requirement: Обработка ошибок API
#### Scenario: Обработка ошибки авторизации
Given система отправляет запрос с неверными учетными данными
When API возвращает ошибку 401
Then система выбрасывает FreshdeskApiException

#### Scenario: Обработка ошибки лимита запросов
Given система отправляет слишком много запросов
When API возвращает ошибку 429
Then система делает паузу и повторяет запрос
